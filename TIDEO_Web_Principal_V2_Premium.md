# TIDEO — Web Principal V2 Premium

> **Documento de contenido y dirección web para `www.tideo.tech`**
> Versión rearmada a partir del estudio de webs premium de consultoras, estudios digitales y agencias globales.
> Objetivo: construir una web principal sobria, editorial, estratégica y de alta percepción de valor, sin mezclar todavía portal, campus, ERP SaaS ni zonas privadas.

---

# 1. Cambio de enfoque

La primera versión de la web de TIDEO no debe parecer una web genérica de "servicios tecnológicos". Debe sentirse como una firma moderna de estrategia, tecnología y producto digital.

El enfoque anterior explicaba mucho qué es TIDEO.
El nuevo enfoque debe demostrar autoridad antes de explicar.

## Principio rector

```text
El trabajo, la claridad estratégica y la prueba visual deben convencer antes que la lista de servicios.
```

La web debe comunicar:

- Ambición.
- Criterio estratégico.
- Capacidad técnica.
- Diseño premium.
- Resultados de negocio.
- Confianza para empresas medianas.
- Diferenciación frente a ERPs rígidos, agencias de software y consultores tradicionales.

---

# 2. Qué aprendemos del benchmark y cómo aplicarlo a TIDEO

## Patrones detectados en webs premium

| Patrón observado | Cómo aplicarlo en TIDEO |
|---|---|
| Hero audaz, corto y no descriptivo | Evitar "somos una empresa de transformación digital". Usar una frase con carácter. |
| Work/Cases antes que Services | Mostrar soluciones, prototipos, casos tipo o proyectos seleccionados antes de listar servicios. |
| Modo oscuro o monocromático | Usar una estética dark premium con blanco, azul profundo y acentos por división. |
| Mucho whitespace | No saturar con íconos, textos largos ni bloques corporativos densos. |
| Tipografía grande y editorial | Titulares muy grandes, frases cortas, jerarquía visual potente. |
| Logos, métricas y prueba social | Distribuir confianza a lo largo de la home, no solo al final. |
| Insights visibles | Mostrar pensamiento propio: IA, procesos, ERP, automatización, Power BI, CRM, etc. |
| CTA conversacional | "Cuéntanos tu proceso" funciona mejor que "Enviar formulario". |

# 3. Objetivo de la web principal

`www.tideo.tech` debe ser la vitrina comercial oficial de TIDEO.

No será todavía:

- Portal de alumnos.
- Portal de vendedores.
- ERP SaaS.
- Intranet.
- Dashboard administrativo.
- Plataforma de cursos.

Sí será:

- Página institucional premium.
- Captador de oportunidades comerciales.
- Portafolio estratégico.
- Presentación del ecosistema TIDEO.
- Puerta de entrada para auditorías, demos y conversaciones B2B.
- Base futura para contenidos, casos e insights.
